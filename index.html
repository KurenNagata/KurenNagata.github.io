            SHABETチーム開発・リーダー

    「顔見知りから親友へ」仲を深めることをコンセプトにしたゲームアプリです。大学のプロジェクト学習「ミライケータイプロジェクト」の中で、12人のチームで開発しています。2026年11月にMVP、12月にストア公開を予定しています。
    
            
    
              
    役割
    サービスリーダー、プロダクトオーナー兼スクラムマスター

    Go、Flutter、TypeSpec / OpenAPI、WebSocket

    • チームにスクラムを導入し、1週間単位のスプリントを回しています
      • 
              
    • タスクの割り振りと進捗の管理、コードや途中経過のレビューを担当しています
      • 
              
    • API の仕様を TypeSpec で書き、OpenAPI に変換してアプリ側とサーバー側で共有しています
      • 
              
    • api・backend・mobile を1つのリポジトリにまとめ、仕様のずれを防いでいます
      • 
            
    
            
    ミライケータイプロジェクト全体では、オープンキャンパス用のポスターやスライドの制作、合同会議での発表も担当しました。

            GET /works/hope-notifier
            HOPE 課題締切通知Bot個人開発
            200 稼働中
          
          
    
            
    大学の学習管理システム（HOPE / Moodle）から未提出の課題を取り出し、締切が近いものを Discord に知らせる Bot です。自分の課題の出し忘れを防ぐために作りました。Claude（AI）を用いて開発しています。

    できること

      • 
              
    • Discord で頼んだ時刻に知らせるリマインド機能
      • 
              
    • root ではない専用ユーザーで動かし、権限を必要な分だけに絞っています

            GET /works/learncode
            LearnCode個人開発
            200 公開中
          
          
    
            
    ブラウザだけで完結するプログラミング学習 Web アプリです。問題を読み、エディタでコードを書き、実行して隠しテストに全部通ればクリア、という流れを軸に、設計から本番公開まで1人で作りました。Claude（AI）を用いて開発しています。
    
            
    
              
    技術
    React、Monaco Editor、Go、TypeSpec / OpenAPI、PostgreSQL（Neon）、Cloudflare Workers、Cloud Run、Docker
    
            
    
            
    設計で工夫したこと
    
            
      
              
    • TypeSpec で API を定義し、OpenAPI から Go のコードを自動生成して仕様とコードのずれを防止
      • 
              
    • handler、service、repository の順に一方向に依存させ、interface で分離
      • 
              
    • 隠しテストの期待値はサーバーの外に出さず、実行時間と出力の量にも上限を設定
      • 
              
    • クリアで経験値とレベルが上がる仕組み、JWT 認証での進捗保存
      •
